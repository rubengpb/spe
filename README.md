## Development

If you are reading this file you have the correct authenticacion. Run this:

### Clone repo

```bash
git clone git@github.com:helarteDeProgrmar/spe.git
cd spe
```

### Build dependencies

```bash
mix deps.get
mix run # check all is correct
```
